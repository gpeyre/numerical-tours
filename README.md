# Numerical Tours

Mathematical data science through complete, executable experiments by Gabriel Peyré and contributors.

Start with the [Python notebooks](python/README.md), or browse [numerical-tours.com](https://www.numerical-tours.com/). The main collection covers imaging, optimization, optimal transport, machine learning, signals, and geometry. All worked examples show their implementations directly in the notebooks.

The `matlab`, `julia`, and `r` folders contain the original language editions. The website source lives on the `gh-pages` branch; Python content lives on `master`.

For installation, execution checks, and website export, see [the maintenance guide](maintenance/README.md).
